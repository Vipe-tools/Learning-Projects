# HTML & CSS Basics
[![HTML5](https://img.shields.io/badge/HTML5-E34F26?logo=html5&logoColor=white)](https://developer.mozilla.org/docs/Web/HTML)
[![CSS3](https://img.shields.io/badge/CSS3-1572B6?logo=css3&logoColor=white)](https://developer.mozilla.org/docs/Web/CSS)

A small learning project created to practice the fundamentals of HTML and CSS.

The project consists of a simple webpage containing different HTML elements and CSS styles used to experiment with page structure, colors, links, buttons, hover effects, backgrounds, spacing, and basic animations.

## Features

* Basic HTML page structure
* Headings and text elements
* HTML classes
* Links and link buttons
* Multiple button styles
* Hover effects
* CSS transitions and transformations
* Background colors and gradients
* Shadows and rounded corners
* File selection input
* Basic page layout and styling

## Technologies

* HTML5
* CSS3

No JavaScript or external libraries are used.

## Purpose

This project was created as a practical exercise to learn and experiment with basic HTML and CSS concepts.

The source code contains extensive comments explaining individual HTML elements and CSS properties.

It is part of the **Learning-Projects** repository and is intended for learning and experimentation rather than production use.
