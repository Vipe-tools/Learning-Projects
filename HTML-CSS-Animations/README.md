# HTML & CSS Animations
[![HTML5](https://img.shields.io/badge/HTML5-E34F26?logo=html5&logoColor=white)](https://developer.mozilla.org/docs/Web/HTML)
[![CSS3](https://img.shields.io/badge/CSS3-1572B6?logo=css3&logoColor=white)](https://developer.mozilla.org/docs/Web/CSS)

A small learning project created to practice CSS animations and positioning.

The project demonstrates basic animation techniques such as:

* movement with `@keyframes`
* color transitions
* rotation
* scaling and pulsing
* diagonal movement
* circular movement
* opacity
* hover effects

The project uses only **HTML** and **CSS** and was created as part of my learning process.
