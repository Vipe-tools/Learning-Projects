# Python Terminal Animation


A small Python learning project that demonstrates a simple interactive terminal interface.

The program includes an animated and color-changing progress bar, terminal cursor control, and keyboard input that can be processed while the animation is running. The entered value is checked and a corresponding colored response is displayed.

## Features

* Animated terminal progress bar
* ANSI terminal colors
* Dynamic cursor positioning
* Keyboard input during the animation
* Input validation and colored feedback
* Exit using the `ESC` key

## Requirements

* Python 3
* Windows

The current implementation uses the Windows-specific `msvcrt` module for non-blocking keyboard input and is therefore intended to run on Windows.

## Purpose

This project was created as a small practical exercise to experiment with Python terminal output, ANSI escape sequences, keyboard input, cursor positioning, and simple terminal animations.

It is part of the **Learning-Projects** repository and is intended for learning and experimentation rather than production use.
